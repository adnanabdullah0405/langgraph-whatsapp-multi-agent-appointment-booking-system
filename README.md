# langgraph-whatsapp-multi-agent-appointment-booking-system
Production LangGraph multi-agent system — 1 supervisor + 6 specialist agents for doctor/lab appointment booking, rescheduling, FAQ (Agentic RAG), and clinic navigation. Bilingual English/Urdu/Roman Urdu. Human-in-the-loop, streaming, persistence. PostgreSQL + Pinecone. 2,000+ daily bookings automated.
